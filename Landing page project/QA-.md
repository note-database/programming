## Round 1 — هویت و استراتژی محصول

### 1) دقیقاً این قالب را برای چه کسی می‌سازیم؟

یکی از مهم‌ترین تصمیم‌های کل پروژه همین است.

گزینه‌ها:

**A. قالب عمومی Personal Portfolio**  
مناسب برنامه‌نویس، طراح، فریلنسر، عکاس، مارکتر و...

مزیت: بازار بزرگ‌تر.  
ضعف: هویت محصول معمولاً Generic می‌شود.

**B. مخصوص Developer / Front-end Developer**  
بخش‌هایی مثل GitHub، Tech Stack، پروژه‌های کدنویسی، Experience و...

مزیت: تمرکز و هویت قوی‌تر.  
ضعف: بازار کوچک‌تر.

**C. مخصوص Creative Freelancer**  
طراح، UI/UX Designer، Photographer، Illustrator و...

**D. ترکیبی ولی با یک مخاطب اصلی**

مثلاً ظاهر و محتوای Demo برای Developer باشد اما ساختار آن به‌اندازه کافی عمومی باشد که Designer یا Freelancer هم بتواند استفاده کند.

**پیشنهاد من: D**

یعنی:

> **Modern Personal Portfolio Template primarily designed for Developers & Creative Professionals**

این کار هم هویت می‌دهد و هم بازار را بیش از حد محدود نمی‌کند.

### 2) خریدار اصلی قالب چه سطحی از دانش فنی دارد؟

**A. مبتدی HTML/CSS**

**B. متوسط**

HTML/CSS/JS را می‌فهمد و می‌تواند فایل‌ها را ویرایش کند.

**C. حرفه‌ای**

می‌تواند architecture را دستکاری کند.

**پیشنهاد من: A + B**

محصول باید برای کسی که HTML مقدماتی دارد قابل استفاده باشد، ولی ساختار کد هم برای Developer حرفه‌ای تمیز باقی بماند.

- رنگ اصلی
- لینک شبکه اجتماعی
- پروژه‌ها
- مهارت‌ها
- اطلاعات تماس

نباید نیازمند جراحی JavaScript باشد.

### 4) شخصیت کلی محصول چه باشد؟

اینجا هنوز درباره رنگ صحبت نمی‌کنیم؛ درباره **Brand Personality** صحبت می‌کنیم.

**A. Corporate / Professional**

مرتب، رسمی، امن.

**B. Minimal / Premium**

فضای خالی زیاد، تایپوگرافی قوی، جزئیات کم ولی دقیق.

**C. Creative / Experimental**

Layoutهای غیرمعمول، animation بیشتر و ترکیب‌بندی جسورانه.

**D. Tech / Futuristic**

Glow، grid، dark interface، code-inspired visuals.

**E. Editorial**

Typography محور، شبیه مجلات و portfolioهای design-oriented.

**F. Hybrid**

مثلاً Minimal + Creative.

**پیشنهاد من: F — Minimal + Creative + کمی Tech**

نه Cyberpunk، نه corporate خشک.

چیزی که وقتی Developer یا Designer آن را می‌بیند بگوید:

> «این مدرن است، ولی سه ماه دیگر هم از مد نمی‌افتد.»
